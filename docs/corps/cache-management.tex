\section{Caching}
\label{sec:caching}

The default cache directory is \texttt{liquidtex-cache}. Relative cache and debug
paths are placed under the TeX auxiliary output directory when
\texttt{use-auxdir=true}; otherwise they are relative to the compilation directory.
LuaTeX can create the cache without shell escape. Use relative, visible output
paths that satisfy TeX's output restrictions.

A cache identity includes the document, complete input paths, selected data,
namespace configuration, rendering action, and external-engine configuration.
A signature checks the contents of templates and all data sources, the bundled
renderer sources, and registered pure filters. Changing input contents invalidates
the entry even when timestamps do not change. Matching basenames in different
directories have separate entries.

\texttt{no-cache} forces each request to render and bypasses persistent cached
output; it does not suppress auxiliary request/result files or inline captures.
Only successful renders are published. A nonzero external exit status raises a
LaTeX error even if the renderer wrote an output file.

Input files are opened through TeX for recorder dependency tracking. Liquid output
digests are recorded in the auxiliary file and request a rerun when they change.
\texttt{latexmk} can therefore notice data-only changes and settle cross-references
on the next run. External-state-dependent templates or filters should use
\texttt{no-cache} because those dependencies cannot be inferred automatically.
