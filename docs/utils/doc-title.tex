\begin{abstract}
  The \pkg{liquidtex} package integrates a
  \seesection{app:liquid-templates}{Liquid-style} templating layer into the
  \LaTeX{} compilation process. %
  It allows authors to incorporate templated, data-driven content into
  their documents by automatically rendering Liquid templates at compile
  time.
\end{abstract}
